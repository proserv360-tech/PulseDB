Connect another PC to PulseDB

Monitor the SQL Server on any Windows PC from the hosted PulseDB. A small agent runs on that PC and talks to PulseDB over outbound HTTPS only. You don't type any server details, passwords or keys.

Before you start

  • The other PC runs Windows 10 or 11 and has SQL Server installed.
  • The Windows user you sign in as can open that SQL Server. If they can connect in SQL Server Management Studio without a password, this is fine.
  • The PC has internet access. Admin rights are not required; Windows may ask permission once if it needs to install the SQL Server driver.
  • You can sign in to PulseDB as an administrator.

Setup

  1. Download the agent

    On your PC
    Openhttps://pulsedb-o8ax.vercel.app
    1. Sign in, then go to Connections → Manage Connections.
    2. Click ⤓ Connect another PC.
    3. PulseDB-Agent.zip downloads. It already contains PulseDB's address and a new agent key.

    Keep the zip private. Its key lets a PC send data to your PulseDB. Give it only to the PC you are connecting, and download a fresh one for each PC.

  2. Copy the zip to the other PC

    Your PC → other PC

    Use a USB drive, email, Teams or a shared folder. Save it anywhere, for example Downloads.

  3. Extract it

    On the other PC
    1. Right-click PulseDB-Agent.zip → Extract All… → Extract.
    2. Move the PulseDB-Agent folder somewhere permanent, such as C:\PulseDB-Agent. The agent runs from this folder, so don't delete it later.

  4. Run setup.cmd

    On the other PC
    1. Open the PulseDB-Agent folder and double-click setup.cmd.
    2. If Windows shows Windows protected your PC, click More info → Run anyway.
    3. Wait 1–3 minutes the first time. Setup installs Node.js and the SQL Server ODBC driver if they are missing, finds the databases, starts the agent and makes it start at every sign-in.

    It finishes like this, with that PC's name and databases:

    ==> Finding SQL Server on this PC OFFICE-PC: SalesDB, Inventory ==> Agent key for https://pulsedb-o8ax.vercel.app Existing key is valid. ==> Installing autostart and starting the agent Done. PulseDB Agent is running and registered with https://pulsedb-o8ax.vercel.app: OFFICE-PC · SalesDB -> connection #81 OFFICE-PC · Inventory -> connection #82

    Close the window. The agent keeps running in the background.

  5. Check it in PulseDB

    In PulseDB, any PC
    1. Refresh PulseDB with Ctrl + Shift + R and open Connections.
    2. Each database appears as <PC name> · <database>:
      M
      OFFICE-PC · SalesDBSQL Server · localhost (as seen by the agent)
      VIA AGENT
    3. Click Test. Expect Connection successful via PulseDB Agent.
    4. Pick it in the connection selector at the top and open the SQL Server screens.

Other SQL Servers on that PC's network

Once the agent runs on a PC, PulseDB can also reach SQL Servers that PC can see, such as another server in the same office. In PulseDB choose Connections → New Connection → SQL Server, enter that server's host (for example SERVER01\SQLEXPRESS or 192.168.1.20) and a SQL login. PulseDB sends it through the agent automatically.

If you run agents on several PCs, use the PC's name as the host rather than localhost, so PulseDB knows which agent to use.

If something goes wrong

What you seeWhat to do
setup.cmd closes at once or mentions Node.jsInstall Node.js LTS from nodejs.org, then run setup.cmd again.
skipped — Login failedThis Windows user has no SQL Server login. Ask your DBA to add one, or add the server in PulseDB with New Connection and a SQL login.
No SQL Server databases foundSQL Server isn't installed on this PC or its service is stopped. Check Services → SQL Server.
PulseDB says the agent is offlineThe PC is off or signed out, or the agent stopped. Sign in to that PC or run setup.cmd again.
This agent has no valid keyIts key was deleted in PulseDB. Download a fresh zip (step 1) and run its setup.cmd.
You deleted some of its databases and want them backRun setup.cmd again on that PC.

Removing a PC

  1. On that PC, double-click uninstall-agent.cmd in the PulseDB-Agent folder.
  2. In PulseDB, open Observability → SDK Integration and delete <PC name> agent. Its key stops working immediately.
  3. Delete that PC's connections on the Connections page.
The agent only reads from SQL Server; statements that change data are refused unless an administrator turns that on in agent.config.json. Its log is PulseDB-Agent\logs\agent.log.
